# Customize your Vivaldi experience even more
With the snippets in this folder you can apply your own CSS-snippets to Vivaldi and tinker with some nitpicky details.
Every folder contains an custom css-file, that modified the UI a tiny bit. This way, you can select, what you want to apply.

There is also an app, that let'S you do it the easy way, by selecting the snippets you want to apply and then it will
generate a new CSS-file for you, that you can load into Vivaldi.
[Vivaldi mod generator](https://demo.saschadiercks.de/vivaldi/)

Before we get started, you need to know how to apply your own CSS-snippets to Vivaldi.

## How to apply UI-mods
1. Visit `vivaldi://experiments` and tick the "Allow for CSS modifications" box.
2. Then go to: `vivaldi://settings/appearance/` and choose a folder to load from. (Place the new CSS there or choose the folder, where you cloned the repository to.)
3. Restart Vivaldi

For more informations head over to:<br/>
https://forum.vivaldi.net/topic/37802/css-modifications-experimental-feature
